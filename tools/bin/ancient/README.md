Herramienta 'ancient' (temisu/ancient, BSD) compilada en Windows con mingw64.
Decomprime formatos de la escena Amiga: IMP! (File Imploder), CrM!/CrM2 (CrunchMania), PowerPacker, StoneCracker, etc.
Compilada desde https://github.com/temisu/ancient (commit clonado el 2026-09-15).
Nota: IMPDecompressor.cpp modificado (addition=0) porque Sanity usa IMP! sin checksum estandar.

Uso:
  ancient.exe identify <archivo>
  ancient.exe decompress <archivo> <salida>
